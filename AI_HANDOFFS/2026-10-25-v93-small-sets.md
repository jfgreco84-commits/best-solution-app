## How it works in the app

- `SKUS` has `set` (short `SET`, 🎁). Cost schedule: $5.25 through Jul 31 2026, $4.80 from Aug 1
  (each period's 2oz + C5-S). **COGS is the two bottles only.**
- **Add-ons are not in COGS** on purpose. Organza bags, cloths, pouches and screwdriver sets are
  logged as Business Purchases, and v83 made those count once, there. Putting them in COGS too
  would count them twice. The Build card shows the all-in cost for pricing.
- **Stock → Garage → 🎁 Build Small Sets:** takes N 2oz + N C5-S out of the garage, adds N to SET,
  and takes N of each add-on off Supplies (never below 0; a shortfall is named in the toast).
  **Break apart** reverses it. Logged in Garage History ("Built 24 Small Sets").
- Supplies added (qty 0, low alert 25, cost per piece): Organza Bag 5x7 (purple), Microfiber
  Pouch, Mini Screwdriver Keychain Set, Organza Bag 6x9 (8oz + C5-L), Organza Bag 8x12
  (16oz/32oz + C5-L). An existing Microfiber Cloths item keeps its count; it gets $0.09 only if
  it had no cost. None of them auto-charge per show (bags count once, as purchases).
- Bag count rule (used only if `supplyFromPurchases` is turned off): a set sold = one 5x7.
- Everything that loops `SKUS` (counts, packs, transfers, truck, online sales, Batman) now shows
  a SET column automatically.
