# v46: the show screen in tabs

**Date:** 2026-09-26 · **Base:** `06cfc36` (v45) · **App version:** v45 → **v46**

## Requested

"The whole show tab is so confusing. Please hide things behind tabs."

## Done

Show screen header (badge, name, location, warnings, passed banner) stays on top, then a 5-button tab bar (`showTabsBarHTML`, `setShowTab`, `showTabOf`). Every section is still rendered; only the chosen pane is shown, so modals, jumps and tests still find everything.

| Tab | What is in it |
|---|---|
| 📋 Today | Truck right now, Transfer Stock, day tabs + day screen (booths, counts, money), Start/End Show at the bottom |
| 🏆 Teams | Team scoreboard, booth tally, who rang it up, reps & workers |
| 💵 Money | Gross/profit, break even, expenses, other expenses, revenue potential vs actual, show-only prices |
| 📦 Stock | Show stock, pre-show calculator, inventory reconciliation, supplies used |
| ⚙️ Info | Show hours, show details, notes, Export CSV / Print, Mark Passed |

Opens on Today. The tab is kept while you stay on the same show and resets to Today on a different show. Stock shows ⚠️ when reconciliation has a mismatch. End Show moved from mid-page to the bottom of Today.

## Verified

All suites unchanged vs v45 (`passed-not-doing` and `product-debt-invoices` same date-sensitive / v42 failures). Each tab rendered at 390px in Chromium, no page errors.
