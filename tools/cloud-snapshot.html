Best Solution: Cloud Snapshot

What this page does: signs in to Supabase for a moment (that creates a short-lived login session on the server), reads your saved app row ONE time, downloads it to this computer as a file, then signs that session out. What it does not do: it sends no save, update or delete to the cloud, and it does not read or change the app's data in this browser. The login is kept in memory only.

Use only when approved. Use a separate browser profile (or a private window) on a computer, not the phone or browser where the app is open. The downloaded file holds private business data: keep it off GitHub.
